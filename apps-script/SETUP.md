# חיבור טופס האישורים לגוגל שיטס (כ-5 דקות)

עושים את זה פעם אחת, מהמחשב.

1. פותחים את הטבלה, ובתפריט העליון בוחרים **תוספים ← Apps Script** (באנגלית: Extensions ← Apps Script).
2. בעורך שנפתח מוחקים את כל מה שכתוב, ומדביקים במקומו את כל התוכן של הקובץ `Code.gs`. שומרים (Ctrl+S או אייקון הדיסקט).
3. בשורה העליונה של העורך בוחרים את הפונקציה **setup** ולוחצים **הפעלה** (Run).
   - גוגל יבקש הרשאה: **Review permissions** ← בוחרים את החשבון שלך.
   - אם מופיע "Google hasn't verified this app": לוחצים **Advanced** ← **Go to … (unsafe)** ← **Allow**. זה הסקריפט שלך, שרץ רק על הטבלה הזאת.
   - בטבלה יופיעו שתי לשוניות חדשות: **אישורי הגעה** ו**הגדרות**.
4. לוחצים **Deploy ← New deployment** (פריסה ← פריסה חדשה), ובגלגל השיניים בוחרים **Web app**:
   - **Execute as:** Me
   - **Who has access:** Anyone
   - לוחצים **Deploy**.
5. מעתיקים את הכתובת שמופיעה תחת **Web app URL** (מסתיימת ב-`/exec`) ושולחים לי. אני אחבר אותה לאתר ואבדוק שאישור ניסיון נכתב לטבלה.

## אחרי שזה עובד

- **אישורי ההגעה** נכתבים ללשונית "אישורי הגעה": תאריך שליחה, שם הילד/ה, אלרגיות (כן/לא) ופירוט.
- **להחלפת קישור הפייבוקס**: משנים את התא B1 בלשונית "הגדרות". האתר יציג את הקישור החדש מיד, בלי לגעת בקוד.
- אם פעם תשנה את הקוד בעורך, צריך לעדכן את הפריסה כדי שהכתובת תישאר זהה: **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**.
